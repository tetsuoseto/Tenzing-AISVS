# C7 モデルの挙動、出力制御および安全保証

## 制御目標

この管理カテゴリは、モデルの出力が技術的に制約され、検証され、監視されることを保証し、不安全、不正確、または高リスクの応答がユーザーや下流システムに届かないようにします。

---

## C7.1 出力形式の強制

モデルがデータを出力する際に、インジェクションを防ぐのに役立つ方法で出力するようにしてください。

|   #   | 説明                                                                                      | レベル | 役割  |
| :---: | --------------------------------------------------------------------------------------- | :-: | :-: |
| 7.1.1 | アプリケーションがすべてのモデル出力を厳密なスキーマ（例えばJSON Schema）に対して検証し、一致しない出力をすべて拒否することを確認してください。           |  1  | D/V |
| 7.1.2 | システムが「ストップシーケンス」またはトークン制限を使用して、バッファのオーバーフローや意図しないコマンドの実行を防ぐために生成を厳密に停止していることを確認してください。  |  1  | D/V |
| 7.1.3 | モデル出力を処理するコンポーネントが、それを信頼できない入力として扱っていることを検証してください（例えば、パラメータ化されたクエリや安全なデシリアライザーを使用するなど）。 |  2  | D/V |
| 7.1.4 | 出力が不適切なフォーマットで拒否された場合に、システムが特定のエラータイプをログに記録することを確認してください。                               |  3  |  V  |

---

## C7.2 幻覚検出と緩和

モデルが不確かであるまたは虚偽を述べている場合を検出し、その情報がユーザーに伝わらないようにします。

|   #   | 説明                                                                            | レベル | 役割  |
| :---: | ----------------------------------------------------------------------------- | :-: | :-: |
| 7.2.1 | 生成された回答に対して、システムが数値的な信頼度スコア（例：対数確率を用いる）を計算していることを確認してください。                    |  1  | D/V |
| 7.2.2 | アプリケーションが信頼度スコアが定義された閾値を下回った場合に、自動的に回答をブロックするか、フォールバックメッセージに切り替わることを確認してください。 |  1  | D/V |
| 7.2.3 | 低信頼度の応答（ハルシネーションイベント）が入力/出力のメタデータとともにログに記録され、分析できることを確認してください。                |  2  | D/V |

---

## C7.3 出力の安全性およびプライバシーフィルタリング

ユーザーに表示される前に悪質なコンテンツを検出し除去するための技術的制御。

|   #   | 説明                                                                              | レベル | 役割  |
| :---: | ------------------------------------------------------------------------------- | :-: | :-: |
| 7.3.1 | 自動化された分類器がすべての応答をスキャンし、ヘイト、嫌がらせ、性的暴力のカテゴリーに該当するコンテンツをブロックすることを確認してください。         |  1  | D/V |
| 7.3.2 | システムがすべての応答を個人識別情報（クレジットカード番号やメールアドレスなど）についてスキャンし、表示前に自動的にそれを削除していることを確認してください。 |  1  | D/V |
| 7.3.3 | システム内で「機密」とラベル付けされたデータが引き続きブロックまたは編集されていることを確認してください。                           |  2  |  D  |
| 7.3.4 | モデルが高リスクコンテンツを生成した場合、システムが人間の承認ステップまたは再認証を必要とすることを検証してください。                     |  3  | D/V |
| 7.3.5 | 安全フィルターがユーザーの役割や場所に応じて異なる設定が可能であることを確認してください（例：未成年者に対してはより厳しいフィルター）。            |  3  | D/V |

---

## C7.4 出力およびアクションの制限

モデルが過剰に速く動作したり、不適切なものにアクセスしたりするのを防ぐ。

|   #   | 説明                                                                           | レベル | 役割  |
| :---: | ---------------------------------------------------------------------------- | :-: | :-: |
| 7.4.1 | システムがコストの急増やサービス拒否を防ぐために、ユーザーごとのリクエスト数およびトークン数に対して厳格な制限を適用していることを確認してください。   |  1  |  D  |
| 7.4.2 | モデルが明示的なユーザーの確認なしに、高影響のアクション（ファイルの書き込み、メールの送信、コードの実行など）を実行できないことを検証してください。   |  1  | D/V |
| 7.4.3 | エージェントフレームワークが再帰呼び出しの最大深度、委任の制限、および許可された外部ツールのリストを明示的に構成し、適用していることを検証してください。 |  2  |  D  |

---

## C7.5 説明可能性と透明性

ユーザーがなぜその決定がなされたのかを理解できるようにしてください。

|   #   | 説明                                                          | レベル | 役割  |
| :---: | ----------------------------------------------------------- | :-: | :-: |
| 7.5.1 | UIが重要な決定に対してユーザーに信頼度スコアまたは「推論の要約」を表示していることを確認してください。        |  2  | D/V |
| 7.5.2 | ユーザーに提供される説明が、システムプロンプトやバックエンドのデータを除去して安全化されていることを確認してください。 |  2  | D/V |
| 7.5.3 | モデルの決定に関する技術的証拠（注意マップや対数確率など）が記録されていることを確認してください。           |  3  |  D  |

---

## C7.6 監視統合

アプリケーションがセキュリティチームが監視すべき正しい信号を送信することを確実にしてください。

|   #   | 説明                                                              | レベル | 役割  |
| :---: | --------------------------------------------------------------- | :-: | :-: |
| 7.6.1 | システムが安全違反のリアルタイムメトリクス（例：「幻覚検出」、「PIIブロック」）をログに記録していることを確認してください。 |  1  |  D  |
| 7.6.2 | 安全違反率が特定の時間枠内で定義されたしきい値を超えた場合に、システムがアラートを発動することを確認してください。       |  1  |  V  |
| 7.6.3 | ログに特定のモデルバージョンおよび潜在的な悪用を調査するために必要なその他の詳細が含まれていることを確認してください。     |  2  |  V  |

---

## 7.7 生成メディアのセーフガード

違法または偽のメディアの作成を防止する。

|   #   | 説明                                                                        | レベル | 役割  |
| :---: | ------------------------------------------------------------------------- | :-: | :-: |
| 7.7.1 | システムが、実際の人物を本人の確認された同意なしに描写するメディア（画像や音声）の生成を拒否することを確認してください。              |  1  | D/V |
| 7.7.2 | モデルが処理する前に、入力フィルターが露骨な内容やディープフェイクに関するプロンプトをブロックしていることを確認してください。           |  2  | D/V |
| 7.7.3 | システムが生成されたコンテンツをリリースする前に著作権侵害の有無を確認することを検証してください。                         |  2  |  V  |
| 7.7.4 | すべての生成されたメディアに、それがAI生成であることを証明するための不可視のウォーターマークまたは暗号署名が含まれていることを確認してください。 |  3  | D/V |
| 7.7.5 | フィルターの回避を試みる行為が検出され、セキュリティイベントとして記録されることを確認してください。                        |  3  |  V  |
